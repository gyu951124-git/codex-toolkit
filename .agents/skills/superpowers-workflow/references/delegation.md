# 위임 계약

## 전달할 맥락

프로젝트 루트의 [.codex/references/workflow-selection.md](../../../../.codex/references/workflow-selection.md)의 「위임 계약」을 읽고 공통 맥락과 쓰기 담당을 전달한다. 이 문서의 나머지 규칙은 Superpowers 위임에 적용한다.

## 리뷰 전달

요구사항, 실제 변경 파일, 비교 기준과 검증 결과를 제공한다. Git 저장소가 아니면 파일과 요구사항을 제공한다. 존재하지 않는 commit이나 비교 기준을 만들어내지 않는다.

구현자의 결론을 정답으로 주지 않는다. reviewer는 실제 파일을 읽고 발견 사항만 반환하며 수정이나 진행 기록 갱신을 하지 않는다.

## 결과와 재개

구현 담당은 상태, 변경 파일과 행동, 실제 검증·미검증, 차단 사항과 다음 행동을 반환한다. 리뷰 담당은 검토 범위와 결함의 위치·조건·영향·근거·수정 방향을 반환한다.

반복 제한은 [superpowers-workflow](../SKILL.md)의 기준을 따르며 주 agent가 회차를 기록한다. 담당자는 전달받은 현재 횟수와 제한을 따르고 누락·충돌은 주 agent에게 반환한다. 이전 발견 사항과 수정 영향에 집중한다. 중요한 미해결 결함은 완료로 표시하지 않는다. 재개 시 실제 파일과 진행 기록을 확인하고 완료 작업을 재위임하지 않는다.
